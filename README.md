# VR OI · 校园突围

纯前端 Three.js 游戏：OI 考场、保安战斗、走廊突围与庭院校门。

**[在线游玩](https://tangyixiao.github.io/vr-oi-simulator/)**

原作 Deng Ziqian，2.0 改编 Jian_Yu / aakaakii，校园突围版 Tangyixiao。保留 MIT 许可证；本地 Three.js 0.128.0 的许可证在 `assets/vendor/three-LICENSE.txt`。

## 玩法

- WASD 移动，Shift 疾走，空格跳跃，鼠标转向，Esc 设置。
- 左键攻击，E 交互，1 拳头、2 手枪、3 自动步枪、4 加特林；挑战持枪时 R 换弹，近战时 R 拾取／放下空椅子，F 干扰同学，H 举手。椅子可在切枪时收起，切回拳头后按 R 重新拿出。
- 爽快近战：100 米、360°、无冷却，拳头伤害 100、椅子 150。挑战近战：拳头 2.4 米／90°／伤害 35，椅子 4 米／120°／伤害 70，同样无冷却。
- 爽快模式手枪、步枪、加特林均为真正无限子弹，无需换弹。挑战模式手枪 12 发、步枪 30 发、加特林 200 发，备用弹药无限，换弹分别需要 1／1.5／2.5 秒。手枪点射，步枪与加特林按住左键连射；每发伤害分别 60／35／18，加特林每秒 25 发。
- 两种战斗模式的枪械均按准星命中最近目标，射程 100 米，墙壁、台地、掩体和场景物体会挡住子弹。每发最多伤害一人，血量归零才计入击倒。
- 保安主动绕过桌子和墙角，从不同方向包围后收拢追击；近距离适当避让。开始界面与暂停设置均可调基础移速（0.5～10 米／秒，默认 1.5），立即生效并自动保存。远距离追击及校园关卡会加速。
- 保安站立行走，有摆腿与摆臂，停止后回到站姿。每人独立血量，默认 100；开始界面与暂停设置可调 10～2000，修改时保留受伤比例。受伤保安头顶显示血条。
- 同学会按自己的顺序和速度写本局四道题，电脑显示当前题目、进度和完成状态。先用 F 干扰三次使其离座，或在战斗中放倒同学；对其电脑按 E，再点“抄到我的 IDE”。抄到已完成的同题代码后原样提交可游戏 AC；未完成或修改后的代码继续普通模拟评分。完成时间和题目随比赛时间变化，抄代码凭据随存档恢复。
- 剧情：打倒老师开启保安战斗；开局可设 50～5000 名考场保安。清空后在白光出口按 E，选择原结局或继续校园突围。
- 第二关：走廊两个封锁点，然后庭院校门。每段清空后靠近出口按 E。进入第二关恢复三格血，段间不回血。第二关敌人数为考场人数的一半，向上取整。
- 校园新增高低台地、连接坡道和掩体；玩家与保安沿坡道上下，视点随地面和跳跃高度变化，保安从坡道追到台地。出口的中间路线保持畅通。
- 无尽：直接开始战斗，无考试倒计时；死亡或主动结束时记录战绩，爽快和挑战分别保存最佳纪录。
- 默认标准画质、清晰舒适特效。可切换低／高画质、原版强特效，独立开关拖影、抖动、闪烁和碎块。

答题得分是**娱乐模拟评分**，按代码结构与关键词估算；已实际抄取的同学完成代码可获得游戏 AC。不编译或运行 C++，同学代码不代表题目的真实参考答案。注释与空白行不会带来长度奖励；击倒老师后也保留娱乐分数，答题与战斗分别统计。

新增成就包括一拳超人（单次至少 50 人）、椅子战神、同学击倒、校园突围与无尽 500／1000 人。“一人军队”需要完成至少 200 人的考场战斗；低画质同时在场上限 24 人，因此一拳超人需标准或高画质。

## 本地运行与验证

完整下载仓库后可直接打开 `index.html`，也可以运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765`。Three.js 随游戏提供，运行不依赖外部 CDN。

可选开发测试（游戏运行不需要 npm）：

```sh
npm ci
npm test
npm run check
npm run test:browser
```

浏览器测试需要上面的本地服务与 Chromium，默认 `/usr/bin/chromium`；可通过 `CHROMIUM_PATH` 指定浏览器，通过 `TEST_URL` 指定地址。截图写入忽略目录 `.work/`。

## 存档

设置自动保存在浏览器本地。兼容旧答题存档；剧情战斗从最近的阶段检查点重开，保留检查点的模式、武器、枪械弹匣与阶段前累计数据，不恢复中途位置。旧存档的枪械默认满弹匣。开局取消“继续上次进度”可开始新局。失败会保留娱乐分数，点击“从检查点重试”后即可恢复。无尽只保存最佳纪录，不覆盖剧情存档。

## 模块

逻辑仍使用传统脚本，共享全局作用域并按 `index.html` 顺序加载。`gameplay.js` 管理规则和补充队列，`weapons.js` 管理椅子，`firearms.js` 管理枪械与弹匣，`combat.js` 管理独立血量，`navigation.js` 管理共享路线和包围追击，`terrain.js` 管理地面与坡道，`npc-gen.js`／`npc.js` 管理同学进度与抄代码，`campaign.js` 管理关卡与检查点，`upgrade-ui.js` 管理玩法和设置。

在 `assets/problems/` 添加题目后，将脚本加入 `index.html`；每题注册到 `PROBLEM_DATA`，沿用现有格式。
