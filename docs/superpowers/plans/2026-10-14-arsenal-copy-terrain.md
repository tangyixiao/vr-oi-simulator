# 加特林、抄代码与地形实现计划

**Goal:** 修复坐姿保安并完成用户追加的三组玩法。

**Architecture:** 独立分工修改不同文件，通过伤害函数、步态函数、地面高度函数和 NPC 面板初始化／更新函数连接现有传统脚本。

**Spec:** `docs/superpowers/specs/2026-10-14-arsenal-copy-terrain-design.md`

## 全局约束

- 保持离线资源、现有存档兼容及游戏模拟评测标识。
- 同学面板与枪械数字键不争用；血量归零才统计击倒。
- 高低地形、保安追击和跳跃使用同一个地面采样结果。

## 任务

- [x] 加特林、独立可调血量和世界血条；覆盖伤害、击倒、实时调整、连射状态限制。
- [x] 不同同学的做题时间表、可复制面板、同题完成代码游戏 AC、取得记录与存档验证。
- [x] 站立／行走保安和校园坡道／台地／掩体，覆盖移动和导航边界。
- [x] 整合 HTML、按键与说明，更新既有浏览器用例的伤害预期。
- [x] 单元测试 88/88、48 个脚本语法检查通过；新玩法与 NPC 正常操作浏览器流程已通过。用户要求“直接推送不要复核了”，停止最后一轮浏览器回归与独立复核，直接提交推送。

## 重点复核

- 修改保安最大血量不能重置受伤百分比或影响其他保安。
- 有限连射补偿不能在暂停后多发射击。
- 抄到未完成代码或编辑完成代码不能凭旧记录 AC。
- 验证实际保安模型而非只验证寻路；移动和站立姿势都检查。
- 站台上下与落地、各关卡进出、刷怪配额和存档恢复可用。
