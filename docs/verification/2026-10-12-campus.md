# 校园突围验证记录

Node.js 回归测试覆盖攻击方向与距离、无冷却切换目标、人数限额、阶段分配、暂停／弹窗、50 人单次成就、中性词、老师退场、评分空行／注释及结束后的评分回调。

20 项 Node.js 测试通过，45 个脚本语法检查通过。

浏览器覆盖实际 R／E／左键输入、椅子和电脑独立交互、200 人考场与 100 人第二关、武器保留、检查点、无尽超过 1000 人、本地资源、旧存档迁移、失败分数与检查点重试、场景清理和手机宽度布局。

## 持续负载

两版本在相同视口下运行 30 秒脚本负载：每秒清理并补充最多 16 名保安。基线用原版特效，新版用默认标准画质／舒适特效。

| 指标 | 基线 | 新版 |
| --- | ---: | ---: |
| 帧耗时中位数 | 361.2 ms | 184.5 ms |
| 帧耗时 P95 | 632.3 ms | 296.5 ms |
| 结束时几何资源 | 2561 | 72 |
| 结束时碎块 | 3824 | 120 |

这是软件渲染与不同默认特效的对比，不能直接当作真实 GPU 的帧率承诺。

新版无尽战斗持续 5 分钟，击倒 2056 人；每分钟采样的几何资源稳定在 44、纹理稳定在 4，碎块 107～120，未结束或出现脚本异常。

随后连续切换关卡 15 次，预热后几何资源维持 49～50，纹理 2～3，没有随次数持续增长。

## 复核

独立代码复核发现的过期评分回调、洗手间延迟回调、失败分数显示、椅子落点及 NPC 几何回收问题均已修复。新增回归测试验证评分不能在结束或切关后写入；复核确认无剩余重要缺陷。

额外密度测试：在标准画质与低帧率补充速度下生成 64 名保安，实际左键椅子攻击一次全部击倒并解锁两个成就；独立特效开关与低画质设置在刷新后恢复。
